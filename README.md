## Getting Started

This project uses pnpm, make sure to set it up before going forward.

### Installing dependencies

```bash
pnpm install
```

### Start the development server

```bash
pnpm dev
```

### Build for production

```bash
pnpm build
```

### Start the production server

```bash
pnpm start
```
